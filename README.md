🛍️ Vrinda Store Data Analysis

📌 Project Overview

Vrinda Store Data Analysis is an Excel-based data analysis project that explores the store's 2022 sales and order information. The workbook contains an order-level dataset and summary analysis sheets covering monthly sales, order counts, customer demographics, order status, sales by state, and sales channels.

The purpose of this project is to organize retail sales data into meaningful summaries so that business performance and customer purchasing patterns can be understood more easily.

🎯 Project Objectives

Analyze monthly sales amount and order volume.

Compare sales contributed by men and women.

Understand the distribution of order statuses.

Identify the top-performing states by sales amount.

Examine order distribution across sales channels.

Explore customer age-group and gender patterns.

Present key business information in a structured Excel workbook.

🧰 Tools Used

Microsoft Excel – data organization, spreadsheet analysis, formulas and summary tables.

Pivot-table-style summaries – aggregation of sales and order information.

Excel charts / visual summaries – presentation of trends and comparisons, where included in the workbook.
